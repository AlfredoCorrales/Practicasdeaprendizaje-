# TecnoShop - Proyecto de práctica

Proyecto sencillo de una tienda de productos tecnológicos.

Este proyecto será utilizado para practicar:

- Git y GitHub
- Clonar repositorios
- Trabajar con Visual Studio Code
- git status
- git add
- git commit
- git push
- git pull
- Modificación de archivos

- Proyecto para aprender Git y GitHud
- Tener mayores conocimientos
- Sistema de tienda virtual de productos tecnológicos
