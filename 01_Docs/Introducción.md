# Bienvenido a TecnoShop

## ¿Qué es TecnoShop?

TecnoShop es una tienda virtual dedicada a la venta de productos tecnológicos. En esta plataforma los usuarios pueden consultar diferentes productos y conocer información sobre ellos.

## ¿Qué ofrece el proyecto?

El proyecto busca facilitar la consulta de productos tecnológicos mediante una página web sencilla, organizada y fácil de utilizar.

## Objetivo

El objetivo principal es desarrollar una plataforma web que permita mostrar productos tecnológicos de manera clara y accesible.
